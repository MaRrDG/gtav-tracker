# gta5-tracker — instrucțiuni de proiect

## Git

- **Fără trailer `Co-Authored-By`** în mesajele de commit. Fără `🤖 Generated with...`.
  Mesajul de commit conține doar ce s-a schimbat și de ce.
- Format mesaj: `type(scope): subject` — de ex. `feat(map): render objective markers`.
- Branch de lucru: `dev`. Nu există `main`. Nu se face `git push` — împinge userul.
